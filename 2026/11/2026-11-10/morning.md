## 1. Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2，API 价格下调

## 2. Meta 发布轻量模型 Muse Ember，面向智能体高频任务

Meta 11 月 9 日推出其最小、最高效的模型 Muse Ember（muse-ember-1.0），面向工具调用、编码子任务、路由、信息抽取和长文档解析等智能体日常重复工作。官方定价为每百万输入 token 0.10 美元、每百万输出 token 0.50 美元，上下文窗口为 100 万 token，最大输出约 51.2 万 token，已在 Meta Model API 与 Muse Code 上线。

## 3. 谷歌扩充第八代 TPU：新增机密推理 8tx 与长上下文 8i Max

谷歌 11 月 9 日宣布在第八代 TPU 产品线中再推两套系统：TPU 8tx 与 TPU 8i Max，至此同一代已推出四套系统。8tx 基于与 8t 相同的芯片并搭配 AMD 主机处理器，在硬件层隔离推理中的敏感数据与模型权重，面向受监管企业与政府场景；8i Max 将两枚 TPU 8i 封装在同一封装上，官方称算力、片上 SRAM 与高带宽内存带宽均较 8i 翻倍，用于处理代码库或长视频等大上下文任务。
