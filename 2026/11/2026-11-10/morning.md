## 1. Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2，API 价格下调

Anthropic 于 11 月 9 日发布 Claude Fable 5.2 与 Mythos 5.2，二者为同一底层模型，面向高难度编程、推理与视觉等技术工作。Fable 面向全部用户，Mythos 仅对通过网络安全或生命科学核验的机构开放；官方称生成速度较 5.1 最高快约 30%，标准 API 价格降至每百万输入 token 8 美元、每百万输出 token 40 美元，并已登陆 Claude 平台以及 AWS、Google Cloud 与 Microsoft Azure。
